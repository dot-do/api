# monthend.finance — wave zero (register row `fn-finance`)

The month-end close as a typed, verifiable surface: **the Ledger + ten typed
close deliverables** (trial balance → month-end package), instantiated from
one row of the full-economy property register per the property-template spec
(`studio/docs/plans/2026-08-23-property-template-spec.md`).

## What serves

| Surface | Address |
|---|---|
| Capability card (AXP, probe manifest, top-level `g2`, `links.verify` + `links.icp`) | `/.well-known/agents.json` |
| OpenAPI 3.1 (live-only, canonical `operationId` on every operation) | `/openapi.json` |
| Pricing Document (metered, `binding: false` + statement, operationId-keyed `rates[]` top-level — axp-ext-rates-g2) | `/pricing` (+ `.json/.md/.html`) |
| llms.txt (H1 + family tail) | `/llms.txt` |

| One deliverable / one ledger | `/close-deliverables/{id}` · `/ledgers` · `/ledgers/{id}` |
| Per-outcome order door — typed 402 OFFER, **labeled stub, no billing** | `POST /orders` |
| 402 offer probe | `/offer` |
| G2 coordinates (ICP, personas, agent classes, System coordinate) | `/icp.json` |
| Published suite + run-our-tests page | `/verify` · `/verify/suite.json` |
| Three-faced home (conneg: JSON / markdown / HTML) | `/` |

- **G3 substrate**: `product.js` (APIProduct instance — Nouns with schema +
  binding + verbs, System coordinate Accounting⟨finance-departments⟩,
  operations, sandbox spec, meters).
- **G4 projection**: `projection.config.json` (brand, ICP + personas, motion
  `B2A2B`, offer array, per-outcome pricing pattern, experiment registration).
  monthend.finance is itself the human-vocabulary name for the close
  function; its HTML face carries zero API/agent vocabulary.
- **Seed** (`seed.js`): synthetic, deterministic, generated from a balanced
  double-entry journal for a fictional company — the trial balance ties by
  construction; every record is labeled `example: true`. Two full close
  cycles (2026-06, 2026-07), all ten deliverable types each.
- **Seams** (`seams.js`): metering / money / receipt / signal events tagged
  `{substrate, projection, motion, operation, shape, pattern}`; Analytics
  Engine binding `SEAMS` when bound, constructed-and-dropped otherwise.
