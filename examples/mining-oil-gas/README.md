# mining-oil-gas — wave-zero machine face (GAP row)

The wave-zero instantiation of the **`mining-oil-gas`** register row (Mining,
Oil & Gas — NAICS 21: 211 extraction, 212 mining/quarrying, 213 support),
built to the property template spec
(`studio/docs/plans/2026-08-23-property-template-spec.md`).

**This is a GAP row**: no apex name is held at any ladder rung (artifact
singletons only: `minesafety.dev`, `jib.claims`, `tankcheck.dev`), so per spec
§0 the G3 substrate is instantiated under a placeholder org.ai address
(`mining-oil-gas.org.ai`) and **no G4 brand config exists** — the brand
attaches when a name is acquired (#16). See `REGISTER-NOTE.md` for the GAP
record, the honest source-route probe, and the recorded blockers.

All sandbox data is **synthetic example data, always labeled** — `example:
true`, `[demo]` name prefixes, synthetic `00-` state-prefix well API numbers
(00 is not a real state code), no real company/person/mine/well names, and
regulatory classification codes (30 CFR cites, CAS numbers) **omitted, never
fabricated**.
