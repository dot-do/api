# fn-product-development — wave-zero machine face (GAP row)

The wave-zero instantiation of the **`fn-product-development`** register row
(Function: Product Development — one of the 13 APQC Functions), built to the
property template spec (`studio/docs/plans/2026-08-23-property-template-spec.md`).

**This is a GAP row**: no product-function name is held, so per spec §0 the G3
substrate is instantiated under a placeholder org.ai address
(`fn-product-development.org.ai`) and **no G4 brand config exists** — the
brand attaches when a name is acquired (#16). `apis.dev` is deliberately NOT
this rail (#3: its ratified subject belongs to the Software vertical).

All sandbox data is **synthetic example data, always labeled** — `example:
true`, `[demo]` title prefixes, GS1 demo-prefix-952 GTINs with valid check
digits, no real company or person names.
