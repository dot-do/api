# api.equipment — wave-zero machine face

The `fn-facilities-assets` substrate (Function: Facilities & Assets, one of
the 13 APQC Functions) projected as **api.equipment** — the rail an agent
calls to get equipment: asset registry records (GIAI/GTIN identity spine),
maintenance work orders, equipment-model catalog identity, and Digital
Product Passport records (EU battery DPP statutory clock: 2027-02-18).

Built per the property template
(`studio/docs/plans/2026-08-23-property-template-spec.md`) from the register
row `fn-facilities-assets`
(`studio/docs/plans/registers/2026-08-23-full-economy-property-register.json`).

**Status: wave zero, not deployed.** Everything served is a labeled example
corpus (`example: true` on every record; GS1 demo prefix 952 with computed
valid check digits on every identifier) — the live product surface over
simulated data, never a faked demo. Prices are stated intent
(`binding: false`); 402 boundaries are served and typed; **settlement is not
activated — no charge is collected.**

**Source-route honesty (C-class row):** the row's route is per-asset-class
registries built the Vindex way (manufacturer identity ingest + first-party
events). No manufacturer feed is honestly reachable at wave zero, so the
EquipmentModel catalog is labeled synthetic §5.2 seed and **class-A status is
claimed nowhere on this surface**; the ingest ladder is recorded on the Noun's
binding note in `substrate.mjs`.

  Vendored from axp.org.ai COMMITTED HEAD
  `523c9ef217d54feefb0b20734a6d2996a6965b79` (`draft/axp-extension-rates-g2`)
  via `git show` — recorded in `axp/VENDORED.json` and gated in

- **Seams (§7.4):** `seams.mjs` — metering events tagged

## Primacy record (batch watch list)

The register carries **no primacy ruling** for the work-order record type,
which the FSM grain names on three rows (facilities-services,
repair-field-services, this row), and sibling wave-zero substrates
(fn-service-delivery, waste-remediation) already define work-order-shaped
records under their own row keys. This build defines `MaintenanceWorkOrder`
and `Asset` **under the `fn-facilities-assets` row key only**, records the
collisions (`substrate.mjs` header + `projection.mjs.primacy`), and **claims
nothing shared** — no shared abstraction, no cross-row type reference.
