# api.services — wave-zero machine face

The `fn-service-delivery` substrate (Function: Service Delivery, one of the 13
APQC Functions) projected as **api.services** — the generic demand rail of the
api.* singular family: the front door where the as-a-Service spectrum resolves
for machine callers.

Built per the property template
(`studio/docs/plans/2026-08-23-property-template-spec.md`) from the register
row `fn-service-delivery`
(`studio/docs/plans/registers/2026-08-23-full-economy-property-register.json`).

**Status: wave zero, not deployed.** Everything served is a labeled example
corpus (`example: true` on every record) — the live product surface over
simulated data, never a faked demo. Prices are stated intent
(`binding: false`); 402 boundaries are served and typed; **settlement is not
activated — no charge is collected.**

## Architecture (template mapping)

- **G3 (Stratum A):** `src/product.js` — the APIProduct instance: 4 Nouns
  (Service `generated`, Engagement/WorkOrder/Outcome `native`), PSA+FSM system
  coordinates, operations register, sandbox + suite + meters.
- **G4 (Stratum B):** `src/projection.js` — brand, ICP/personas, `motion: B2A`
  (the #17 ladder exclusively; no OAuth/CC gates), offer rungs 0–3 (rung 0
  live, 1–3 labeled stubs), 402-metered-per-call experiment registration,
  counterpart-brand gap recorded.
- **Quartet:** generated by the vendored `axp-faces` 0.3.0 (`src/axp/`,
  byte-identical at `PINS.json`, spec pin `apis-ax-axp@2.6.0`, digest
  `a9a1197c…`, extension pin `axp-ext-rates-g2@0.2.0`). The template's carried
  open question #1 is CLOSED: `rates[]`, `operationId`, `links.verify`, and
  `g2` are native manifest inputs at the ruled placements — the former
  `src/rates.js` bridge extensions are deleted.
- **Seams (§7.4):** `src/seams.js` — metering events tagged
  `{substrate, projection, motion, operation, shape, pattern}`, money +
  receipt stubs on 402 boundaries, traffic events with identity class
  (id.org.ai grain where presented) × referral. Wave-zero channel: structured
  stdout; the unified analytics plane attaches after extraction.
