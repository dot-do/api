## What serves

One substrate, two plies (same manifest rows, same envelopes, same rate rows):

- **Data face** — `GET /manifests` (the branching collection — the row's
  statutory-record position), `GET /manifests/{id}`, `GET /facilities`
  (**REAL EPA ECHO RCRA handler records**, `ingested` binding, provenance on
  every record), `GET /facilities/{handlerId}`, `GET /scale-tickets`,
  `GET /waste-profiles` (`generated` binding, derived from the manifest corpus)
- **Headless route/dispatch face** — `POST /manifests` and
  `POST /work-orders` (create, into the ephemeral anonymous sandbox
  workspace), `POST /work-orders/{id}/complete` (completes the order and
  mints its scale ticket; the seed tenant is read-only and answers BLOCKED)
- **The AXP quartet** — `/.well-known/agents.json`, `/openapi.json`,
  `/pricing`, `/llms.txt` — generated by the vendored `axp-faces` (0.3.0) at
  the ratified pin (`apis-ax-axp@2.6.0`, digest `a9a1197c…`) plus the ratified
  generator extension `axp-ext-rates-g2@0.2.0` (top-level `rates[]` in the
  Pricing Document, canonical camelCase `operationId` on every operation,
  `links.verify`, and the top-level `g2` card object — all native manifest
  inputs, never hand-rolled)
- **MCP door** — `POST /mcp` (JSON-RPC 2.0): `listManifests`, `getManifest`,
  `listFacilities`, `listWasteProfiles` — the same data functions the HTTP
  routes call
- **G2/G3 exposure** — `/icp.json` (the card's `links.icp`), `/substrate.json`
  (the `APIProduct` instance), `/verify` (claims as runnable probes, 3 faces)

## Data honesty (the EPA-class feed split)

The row's source route was **probed honestly in-session (2026-08-23)**:

| Feed | Probe result | Consequence |
| --- | --- | --- |
| EPA ECHO RCRA facility search (`echodata.epa.gov`) | keyless `200`, real records | **Facility is REAL ingested data** (Class A, public domain, 17 U.S.C. § 105) — `facilities.real.mjs`, provenance on every record, refresh via `scripts/ingest-facilities.mjs` |
| EPA e-Manifest / RCRAInfo REST (`rcrainfo.epa.gov`) | `401` — registered credentials required | **Manifest stays labeled synthetic seed** (spec §5.2); the e-Manifest ingest is the first rung of the row's enrichment ladder |

Synthetic sandbox records (`seed.mjs`) are **labeled example data** —
deterministic corpus, 952 demo prefixes, EX9 synthetic handler ids,
Example-name companies, example.com emails, `example: true` on every record —
and **never reference the real ECHO parties**, so no real company is depicted
doing a fictional thing. The sandbox is the real product over simulated data,
never a faked demo.

Pricing is a **402-shaped stub, labeled as such** in the `/pricing` statement
(`binding: false`): the OFFER boundary is real and typed, rate rows price
from zero or carry free quotas, and nothing bills. Metering / money / receipt
**seams** are emitted as structured logs tagged
`{substrate, projection, motion, operation, shape, pattern}` plus identity
class and referral source (spec §7.4 — seams only, no billing logic).
